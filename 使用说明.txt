数控车削仿真项目

双击根目录“打开仿真.cmd”进入平台；双击“陀螺/打开陀螺演示.cmd”进入陀螺实验。
本地离线运行，无需安装或启动服务器。载入/修改程序后先检查，再播放或查看成品。
程序及导出统一使用.txt，图纸使用SVG。

目录
主体项目/：唯一界面、仿真引擎、材料扫掠、刀具、碰撞检查和测试。
陀螺/：工件定义workpiece.js、一个完整程序、轮廓/工艺说明及SVG尺寸图。
示例程序/：五个独立基础练习.txt，包括直线/圆弧、粗精外圆、径向切槽、螺纹及G00错误示例。
AGENTS.md：已确认工艺与后续维护约定。
验证记录.txt：当前版本的集中验证记录。

陀螺流程
T1/T4前部粗精车 → T2六次直进粗槽 → 粗修留直径0.2mm → 一次连续精修 → 直接切断。
最左柄端为Ø8平直端面，无倒角；精修结束后保持Z-34，直接G01 X0切断。
当前主程序114个编号段，末段N1140；只有一份完整主程序文件。
工件详细坐标见陀螺/轮廓坐标与工艺.txt，刀具参数见主体项目/刀具/刀具参数.txt。

主体项目

index.html：唯一的完整界面入口。
app.js / style.css：实验选择、编辑、播放、刀具侧视和结果显示。
核心/program-flow.js：有限R参数运算与REPEAT展开，保留源码行位置。
核心/engine.js：程序解析、单位与模态检查、进给与吃刀量、材料运动与碰撞。
刀具/tool-model.js：唯一的刀具几何与工艺限制定义。
实验/基础圆柱.js：基础圆柱实验和示例程序来源。
测试/verify.cjs：共享引擎与实验隔离检查。

界面从实验注册表读取工件，不固定为任何一种零件。
实验定义可以提供目标轮廓、切削区域规则、默认毛坯和程序生成器。
刀片/刀颈/刀杆与材料、卡盘的碰撞检查由通用模型执行。

G710：公制几何和进给；G95：mm/r；G97：S按r/min解释。
2ap用于T1/T4等刀具切深；T2的0.2mm用于直径精加工余量。
T3为4mm尖头模型，S350；照片未标尖角，按设置显示。

刀具与工艺参数按实刀设置。工具采用二维XZ截面，未覆盖三维刀座、振动、载荷和工件承接。
可选验证命令（从项目根目录运行）：node --test 主体项目/测试/verify.cjs

T2默认为3mm平底刀，基准为最左侧刃尖，覆盖程序Z到Z+3mm。
粗槽固定Z，一次沿X到目标深度后完全退出，再换槽位；允许侧刃粗修与连续精修。

支持的流程子集：R0–R999赋值；+ - * /、括号、SQRT、ABS、MAXVAL、MINVAL、TRUNC；
坐标/进给/转速使用X=表达式等写法，地址之间用空格分隔。
标记: 后可接赋值或普通指令；REPEAT 标记 P=整数表示追加重复。
仅支持向前方标记返回的有限重复，不接受嵌套或交叠重复、IF、GOTO或任意脚本。
P限1–10000，展开最多16000段、流程最多100000步；未赋值、非有限结果、
除零、负数开方、无效标记等均拒绝。全部展开走刀仍执行原有碰撞与工艺检查。
具体机床的R参数/REPEAT支持范围按对应SINUMERIK型号和配置核对。
语法参考：Siemens Job Planning 10/2015（840D sl / 828D）
https://support.industry.siemens.com/cs/attachments/109481532/PGAsl_1015_en_en-US.pdf

工艺约定见项目根目录AGENTS.md。T2粗槽不会被0.2mm精加工余量拆成啄切。


添加实验工件

每个实验只定义工件、毛坯、加工规则和程序；无需复制主体程序或刀具库。
例如陀螺/workpiece.js通过window.LatheExperiments.top注册实验。
主体项目/index.html只需加载实验定义脚本，界面会从注册表生成实验选项。

实验接口
id / name：唯一标识与显示名称。
stock：默认毛坯、夹持、初始刀位、目标保护开关。
labels：程序选项键与名称。
generate(engine, config)：返回{all, examples}，用于准备和生成程序。
requiredRadius(z, move, tool, config)：可选，给出本工件在该切削中的最小保留半径。
validateCut(toolNumber, position, move, config, toolModel)：可选，返回加工区域错误文字或null。
help / drawing / exportName：实验说明、图纸链接与导出文件名。

Node调用
const engine = require('./主体项目/核心/engine.js');
const experiment = require('./陀螺/workpiece.js');
const result = engine.compile(source, {...experiment.stock, experiment});

刀具参数经config传入，刀具几何只定义在主体项目/刀具/tool-model.js。
工件的requiredRadius和validateCut由引擎调用，其他实验不会继承其尺寸与区域规则。

revision：可选的实验程序修订标识，用于保留旧草稿并独立保存新程序草稿。

外圆与后肩的交接：T1/T4外圆接触终点Z-16.2，越过后肩R1末端Z-16，与T2范围形成0.2mm重叠，避免残尖。
